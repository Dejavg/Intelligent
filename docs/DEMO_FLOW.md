# Demo 演示流程

## 1. 首页

访问：

```text
http://127.0.0.1:8000
```

展示项目名称、项目简介、运行模式、AI 批改结果预览卡、三步演示流程、进入 Demo 按钮和“快速演示：使用固定 5 题数学卷”按钮。首页模式卡会显示“当前可安全演示：是 / 否”；比赛现场建议确认该状态为“是”后再开始演示。

## 2. 学生上传

推荐稳定演示方式：

1. 点击首页或上传页的“快速演示：使用固定 5 题数学卷”。
2. 系统自动选择张三、自动识别 / 答题卡、内置 5 题数学卷图片。
3. 系统自动完成上传、OCR、AI 逐题批改并跳转结果页。

手动演示方式：

1. 点击“进入 Demo”。
2. 选择学生：张三。
3. 选择学科/模式：自动识别。
4. 选择题型：答题卡。
5. 上传固定 5 题数学练习卷图片。
6. 点击“开始 AI 批改”。

系统自动调用：

```text
POST /api/upload
POST /api/ocr
POST /api/grade
```

第一阶段比赛稳定演示建议保持：

```env
DEMO_FIXED_MATH_PAPER_OCR=true
```

此时首页和上传页会显示“当前模式：比赛稳定演示模式”，并用稳定 Demo OCR、逐题批改、过程分、教师复核、班级报告等用户友好标签说明能力；技术配置会以弱化小标签展示。系统会稳定返回结构化 OCR：5 道题的题干、学生答题步骤和整卷标题。真实图片 OCR 可以在第二阶段通过 `DEMO_FIXED_MATH_PAPER_OCR=false` 切回。

真实图片会先进入 OCR 预处理链路。传统 OCR 模式下会执行灰度化、对比度增强、去噪、二值化和倾斜矫正；视觉大模型默认使用原图，可通过 `OCR_PREPROCESS_FOR_LLM=true` 切换为增强图。

如果真实 OCR 模式缺少 API Key，首页会提示“真实 OCR 配置不完整，请检查 API Key 或切换演示模式”；上传、OCR、批改、详情加载、班级分析加载等阶段也会显示明确的加载态和失败原因。

## 3. 批改结果

展示内容：

- OCR 识别结果；
- AI 批改分数；
- 对错判断；
- 过程分维度；
- 解题过程分析；
- 错误原因；
- 正确解法；
- 个性化评语；
- 薄弱知识点；
- 学习建议；
- 整张答题卡逐题批改卡片；
- OCR/预处理诊断提示；
- 学生个人薄弱点报告；
- 推荐讲解顺序卡片；
- 题目快速导航；
- 导出学生个人报告 Markdown；
- 导出 AI 批改 JSON。

比赛讲解重点：

- 总分：`43 / 50`；
- 第 3 题：学生写 `90 - 28 = 72`，系统给 `6 / 10`，标记为“错误”，并指出正确答案为 `62`；
- 第 4 题：移项和合并正确，最后 `3x = 15` 推出 `x = 4` 错误，显示为“部分正确”，得 `7 / 10`；
- 正确题绿色、部分正确黄色、错误步骤红色高亮。
- 右侧总分卡展示 `43 / 50`、正确题、部分正确、需订正、薄弱点和综合评语。
- 逐题卡片展示题干、学生作答、过程分析、错误定位、正确解法、知识点、薄弱点和个性化建议。
- 点击“定位第 3 题”“定位第 4 题”或题目快速导航，可以平滑滚动到对应题目卡片，适合答辩讲解。

## 4. 教师工作台

1. 点击“教师复核”或顶部“教师工作台”。
2. 查看所有学生提交记录。
3. 打开某个学生提交详情。
4. 修改教师分数或评语。
5. 在“逐题复核”区域查看每题题干、学生作答、AI 分数、AI 错因和知识点。
6. 示例：第 3 题可将教师分数改为 `5 / 10`，复核原因写“退位减法错误较明显，扣分应更严格”，并勾选加入标注样本。
7. 点击“保存本题复核”，该题复核会写入教师二次标注。
8. 点击“确认复核”保存整份作业复核。

提交后状态变为：

```text
教师已复核
```

也可点击“返回学生”，状态变为：

```text
已返回学生
```

## 5. 班级分析

进入“班级分析”页面，展示：

- 平均分；
- 正确率；
- 最高分；
- 最低分；
- 薄弱知识点排行；
- 各题正确率；
- 高频错误；
- 教学建议。

点击“导出报告”可下载 Markdown 格式学情分析报告。

## 6. 管理中心扩展演示

进入“管理中心”页面，可展示后续优化已经落成的工程入口：

1. 新增题库题目，验证题库管理能力。
2. 新增班级，验证多班级基础模型。
3. 批量上传 Demo，为多名学生同时创建提交并自动批改。
4. 打开真实 OCR 测试，查看 OCR_PROVIDER、DEMO_FIXED_MATH_PAPER_OCR、LLM_HAS_KEY 等状态；上传真实试卷后只执行 OCR，展示题目数量、文本长度、耗时和结构化结果。
5. 查看增强版评分准确率评测面板，展示测试样例数、平均分差、评分误差合格率、错因识别准确率、知识点识别准确率、过程分合理率、教师复核一致率和评语完整率。
6. 在样例表格中讲解题型、题目摘要、学生答案摘要、人工标准分、AI 批改分、人工错因、AI 错因和命中情况。
7. 对某条提交保存教师二次标注，用于后续模型优化闭环。
8. 点击“重置演示数据”，确认后清空测试提交并恢复默认演示样例。
9. 返回教师工作台或班级分析页，查看新增数据对报告的影响。

## 7. 3 到 5 分钟讲解顺序

1. 打开首页。
2. 查看“当前可安全演示”状态。
3. 点击“一键演示固定数学卷”。
4. 系统自动完成上传、OCR、批改。
5. 进入结果页。
6. 按讲解顺序讲总分 `43 / 50`。
7. 点击题目导航跳到第 3 题。
8. 讲第 3 题计算错误：`90 - 28 = 72`，正确应为 `62`。
9. 点击题目导航跳到第 4 题。
10. 讲第 4 题过程分：前两步正确，最后一步错误，因此给 `7 / 10`。
11. 导出学生报告。
12. 进入教师工作台。
13. 演示逐题复核和加入标注样本。
14. 进入班级分析。
15. 展示教学建议。
16. 进入管理中心。
17. 展示评测中心。
18. 展示真实 OCR 测试页。
19. 必要时重置演示数据。
