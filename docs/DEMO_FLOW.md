# Demo 演示流程

## 1. 首页

访问：

```text
http://127.0.0.1:8000
```

展示项目名称、项目简介、核心能力和进入 Demo 按钮。

## 2. 学生上传

1. 点击“进入 Demo”。
2. 选择学生：张三。
3. 选择学科/模式：自动识别。
4. 选择题型：答题卡。
5. 上传包含完整题目和学生作答过程的 `jpg/png/jpeg` 图片。
6. 点击“开始 AI 批改”。

系统自动调用：

```text
POST /api/upload
POST /api/ocr
POST /api/grade
```

真实图片会先进入 OCR 预处理链路。传统 OCR 模式下会执行灰度化、对比度增强、去噪、二值化和倾斜矫正；视觉大模型默认使用原图，可通过 `OCR_PREPROCESS_FOR_LLM=true` 切换为增强图。

## 3. 批改结果

展示内容：

- OCR 识别结果；
- AI 批改分数；
- 对错判断；
- 过程分维度；
- 解题过程分析；
- 错误原因；
- 正确解法；
- 个性化评语；
- 薄弱知识点；
- 学习建议；
- 整张答题卡逐题批改卡片；
- OCR/预处理诊断提示；
- 学生个人薄弱点报告。

## 4. 教师工作台

1. 点击“教师复核”或顶部“教师工作台”。
2. 查看所有学生提交记录。
3. 打开某个学生提交详情。
4. 修改教师分数或评语。
5. 点击“确认复核”。

提交后状态变为：

```text
教师已复核
```

也可点击“返回学生”，状态变为：

```text
已返回学生
```

## 5. 班级分析

进入“班级分析”页面，展示：

- 平均分；
- 正确率；
- 最高分；
- 最低分；
- 薄弱知识点排行；
- 各题正确率；
- 高频错误；
- 教学建议。

点击“导出报告”可下载 Markdown 格式学情分析报告。

## 6. 管理中心扩展演示

进入“管理中心”页面，可展示后续优化已经落成的工程入口：

1. 新增题库题目，验证题库管理能力。
2. 新增班级，验证多班级基础模型。
3. 批量上传 Demo，为多名学生同时创建提交并自动批改。
4. 查看评分准确率评测面板，展示内置样例的通过率、错题识别准确率和平均分数误差。
5. 对某条提交保存教师二次标注，用于后续模型优化闭环。
6. 返回教师工作台或班级分析页，查看新增数据对报告的影响。
